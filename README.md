# 🤖 AI Recruitment System

An AI-powered recruitment system that predicts candidate selection chances and provides intelligent career recommendations.

---

## 📌 Project Overview

This project helps recruiters and candidates by automating the hiring evaluation process using Machine Learning and AI.

It analyzes candidate data and provides:

* Selection prediction
* Confidence score
* Missing skills
* AI-generated improvement suggestions

---

## ✨ Key Features

* 🔐 User Authentication (Login / Signup)
* 🧠 Machine Learning Prediction Model
* 📊 Selection Probability with Confidence Score
* ❌ Missing Skills Detection
* 🤖 AI-Powered Recommendations (Groq API)
* 🗄️ Database Integration (PostgreSQL)

---

## 🛠️ Tech Stack

* Python (Flask)
* Machine Learning (XGBoost Model)
* Scikit-learn
* Pandas
* SQLAlchemy
* PostgreSQL
* Groq API

---

## ⚙️ How It Works

1. User logs in or signs up
2. Enters candidate details
3. ML model processes input data
4. System predicts selection status
5. Displays:
   * Result (Selected/Rejected)
   * Confidence score
   * Missing skills
6. AI generates personalized suggestions

---

## 📂 Project Structure

* app.py → Main application
